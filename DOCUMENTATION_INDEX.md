## 🎯 Quick Links

### Setup & Testing
- **Run Backend**: `cd CueFinderBE && dotnet run`
- **Run Frontend**: `cd CueFinderFE\cuefinderfe && npm start`
- **Test Login**: http://localhost:3000
- **Test Credentials**: admin / admin123

### Source Code
- **Backend Auth**: `CueFinderBE/CueFinder.Auth/`
- **Frontend API**: `CueFinderFE/cuefinderfe/src/api/`
- **Frontend Config**: `CueFinderFE/cuefinderfe/src/config/`
- **Frontend Utils**: `CueFinderFE/cuefinderfe/src/utils/`

### API Reference
- **Base URL**: `http://localhost:5000/api`
- **Auth Endpoints**: See AUTHENTICATION_SETUP.md
- **JWT Token**: Stored in `localStorage.authToken`
