DATA FLOW - FETCHING ACCESSORIES
═══════════════════════════════════════════════════════════════════════════════

1. Sidebar button clicked
         ↓
2. setCategory('accessories') 
         ↓
3. App state updates
         ↓
4. refreshListings() called
         ↓
5. Four parallel API calls:
   • cueService.getCues()
   • cueCaseService.getCueCases()
   • billiardTableService.getTables()
   • accessoryService.getAccessories() ← NEW
         ↓
6. Each array marked with itemType:
   • { ...item, itemType: 'cue' }
   • { ...item, itemType: 'case' }
   • { ...item, itemType: 'table' }
   • { ...item, itemType: 'accessory' }
         ↓
7. Combined into single array: setCues([...all])
         ↓
8. CueListContainer passes to useCueFiltering
         ↓
9. Hook filters by category:
   if (category === 'accessories' && item.itemType !== 'accessory')
     return false;
         ↓
10. Filtered array passed to CueGridView/CueListView
         ↓
11. Components render only accessories
         ↓
12. User sees grid/list of accessories


API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

LIST ENDPOINTS:
GET    /api/accessories              → All active accessories
GET    /api/accessories/search       → Search accessories
GET    /api/accessories/filter       → Advanced filtering
GET    /api/accessories/count/active → Count

DETAIL ENDPOINTS:
GET    /api/accessories/{id}         → Single accessory details

USER ENDPOINTS (require auth):
GET    /api/accessories/user/my-accessories → User's accessories
POST   /api/accessories                      → Create new
PUT    /api/accessories/{id}                 → Update
DELETE /api/accessories/{id}                 → Delete
PUT    /api/accessories/{id}/mark-sold       → Mark as sold

IMAGE ENDPOINTS (require auth):
POST   /api/accessories/{id}/images              → Upload images
GET    /api/accessories/{id}/images              → Get all images
GET    /api/accessories/images/{imageId}         → Get single image
PUT    /api/accessories/{id}/images/{id}/primary → Set primary
DELETE /api/accessories/{id}/images/{id}         → Delete image
DELETE /api/accessories/{id}/images              → Delete all

RATING (require auth):
POST   /api/accessories/{id}/rate   → Rate accessory
