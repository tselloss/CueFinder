## 🛡️ How It Works

### Automatic Protection
Every time a migration runs:

```
1. ✅ Create full database backup
   ↓
2. ✅ Verify backup is valid and restorable
   ↓
3. ✅ Count all critical records BEFORE migration
   ↓
4. ⚙️  Run migration
   ↓
5. ✅ Count all critical records AFTER migration
   ↓
6. 🔍 Verify no data was lost
   ↓
7. ⚠️  If data loss detected → Automatic rollback to backup
```

**Result**: Your data is never lost, even if something goes wrong.

## 📋 Quick Start

### Setup (One-time on server)
```bash
ssh cuefinder@<SERVER_IP>

# Create backup directory
mkdir -p /home/cuefinder/backups

# Create first backup
docker exec cuefinder-postgres pg_dump -U postgres -d cuefinder > \
  /home/cuefinder/backups/initial_backup.sql

# Enable daily backups (add to crontab)
crontab -e
# Add line: 0 2 * * * /home/cuefinder/scripts/manage-backups.sh backup
```

### Daily Operations
```bash
# Check backup status
ls -lh /home/cuefinder/backups/

# Run integrity check
docker exec cuefinder-postgres psql -U postgres -d cuefinder -f verify-database-integrity.sql

# Create manual backup
./manage-backups.sh backup
```

### Emergency Restore
```bash
# If something goes wrong
./manage-backups.sh restore /home/cuefinder/backups/cuefinder_backup_YYYYMMDD_HHMMSS.sql

# The system will:
# 1. Ask for confirmation
# 2. Create a safety backup
# 3. Restore your chosen backup
# 4. Restart services automatically
```
