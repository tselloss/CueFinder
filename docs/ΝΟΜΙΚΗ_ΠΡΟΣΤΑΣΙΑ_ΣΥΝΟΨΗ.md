## 🛡️ Νέες Ρήτρες Προστασίας

### 1. ⚠️ **Αποποίηση Εγγυήσεων** (AS IS / AS AVAILABLE)
- Η ιστοσελίδα παρέχεται "ΩΣ ΕΧΕΙ"
- Καμία εγγύηση για οτιδήποτε
- **Προστασία από:** Αξιώσεις ποιότητας

### 2. 💰 **Μέγιστη Ευθύνη: €0**
- Το maximum που μπορεί να ζητήσει κάποιος είναι 0 ευρώ
- Γιατί η υπηρεσία είναι δωρεάν
- **Προστασία από:** Αξιώσεις αποζημίωσης

### 3. 🔐 **Indemnification - Αποζημίωση από Χρήστες**
- **Ο χρήστης πληρώνει** αν η πλατφόρμα μηνυθεί
- Ο χρήστης πληρώνει τους δικηγόρους
- **Προστασία από:** Αγωγές τρίτων, copyright claims

### 4. 📝 **Ευθύνη Χρηστών για Περιεχόμενο**
- Admins/creators ΔΕΝ ευθύνονται για user content
- Χρήστης αναλαμβάνει πλήρη ευθύνη
- **Προστασία από:** Copyright, παράνομο περιεχόμενο

### 5. 🗑️ **Δικαίωμα Διαγραφής Περιεχομένου**
- Admin μπορεί να διαγράψει οτιδήποτε
- Χωρίς λόγο, χωρίς προειδοποίηση
- **Προστασία από:** Υποχρέωση να διατηρείς προβληματικό content

### 6. 🔧 **Καμία Εγγύηση Διαθεσιμότητας**
- ΔΕΝ εγγυάται 24/7 λειτουργία
- ΔΕΝ ευθύνεται για downtime, hacking
- **Προστασία από:** SLA απαιτήσεις

### 7. 🇬🇷 **Ελληνικό Δίκαιο & Δικαστήρια**
- Μόνο Ελληνικά δικαστήρια
- Μόνο Ελληνικό δίκαιο
- **Προστασία από:** Διεθνείς αγωγές

### 8. ⚖️ **Διαχωρισμός Ρητρών**
- Αν μία ρήτρα είναι άκυρη, οι άλλες παραμένουν
- **Προστασία από:** Πλήρης ακύρωση των όρων
