Test Users Don't Exist in Database
8 tests affected CRITICAL
Tests use 'testuser' credentials which are not registered. Login endpoint returns "Invalid username or password". This affects all API-based login tests.
Solution: Create a Playwright global setup file that registers test users before running tests, or implement database seeding.
localStorage Cross-Origin Access Restriction
9 tests affected CRITICAL
The isLoggedIn() helper tries to read localStorage which fails with "Access is denied" - this is a browser security policy. Occurs when checking if user is authenticated.
Solution: Wrap localStorage operations in try-catch blocks to handle DOMException gracefully.
